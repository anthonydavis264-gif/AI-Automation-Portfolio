## Overview

A business-operations workflow that analyses incoming issues, assigns priority, recommends actions, flags human-review requirements, and routes records through conditional paths.

## Key Features

- Analyses incoming issues.
- Assigns priority.
- Recommends actions.
- Flags human-review requirements.
- Routes records through conditional paths.

## Workflow

1. An incoming operational issue is received.
2. The issue is analysed and assigned a priority.
3. Recommended actions and any human-review requirement are identified.
4. The record is routed through the relevant conditional path.
